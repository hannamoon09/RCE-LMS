# 검증 자료

이 폴더의 PNG 25개는 로컬 개발 seed 또는 자동 생성한 E2E 계정으로 수행한 화면 검증 기록입니다. 표시된 이름·학번·점수·제출 파일명은 테스트 데이터이며, 프로필 이미지 검증에는 색상 패턴을 사용했습니다. 실제 학생 정보나 운영 업로드 원본을 보관하는 폴더가 아닙니다.

2026-10-13 GitHub 업로드 감사에서 전체 PNG의 화면과 메타데이터를 확인했습니다. 실제 개인정보·사진·평문 비밀번호·PNG 텍스트 및 EXIF 메타데이터는 발견하지 못했습니다. JSON은 검사 결과, 검사 이름과 소스 해시를 보존합니다.

새 자료를 추가할 때에도 테스트 계정을 사용하고 Secret·세션 토큰·실제 개인정보가 보이지 않는지 확인합니다. 실제 운영 화면과 업로드 원본은 이 폴더에 추가하지 않습니다. Playwright 임시 결과와 백엔드 빌드 보고서는 각각 `frontend/test-results/`, `backend/build/`에 생성되며 Git에서 제외됩니다.
